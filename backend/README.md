# Proyecto 15 - Lista de Comprobación 2

## Descripción

Este proyecto es una aplicación web que permite gestionar una lista de usuarios, mostrando sus datos y detalles individuales. Puedes ver todos los usuarios y acceder a la información específica de cada uno mediante rutas dinámicas y tambien informacion de tarjetas de los usuarios

## Tecnologías utilizadas

- Node.js
- Express.js
- JSON para almacenamiento de datos
- Rutas dinámicas con parámetros
- Middleware para manejo de errores

## Funcionalidades

- Listar todos los usuarios
- Ver detalles de un usuario específico
- Manejo de errores cuando un usuario no existe
- Respuestas JSON para APIs simples
